Water Risk Dashboard Guide

About This Dashboard

This interactive dashboard visualizes water risk indicators across different hydrological basins. The data was generated using Python and GIS processing tools, analyzing various water-related metrics at different temporal scales.

Data Processing Methodology

The data was processed using:

  • GeoPandas for spatial data handling
  • Custom Python scripts for basin delineation
  • Hydrobasins dataset integration
  • Automated data cleaning and validation

Each basin is assigned a unique identifier starting with "B_" followed by the last 4 digits of its PFAF_ID and the first 3 letters of its region name.

Understanding Water Risk Indicators

Water Stress (BWS)

Measures the ratio of total water withdrawals to available renewable water supplies.

Water Depletion (BWD)

Indicates the ratio of water consumption to available renewable water supplies.

Interannual Variability (IAV)

Shows the variation in water supply between years.

Using the Dashboard

  1. Select a country to view its hydrological basins
  2. Choose between annual, monthly, or future projection data
  3. Click on basins to select them and view detailed information
  4. Use the time slider for monthly data or scenario selectors for future projections

Visualization Features

  • Interactive map with zoom and pan controls
  • Time series charts for selected basins
  • Network graph showing basin connections
  • Stacked area chart for distribution analysis
